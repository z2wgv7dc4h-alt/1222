# Hard pins for the fragile optional-intern stack. Pass to pip with
#   python -m pip install -c constraints.txt -e ".[intern,pitch,align]"
# (setup.bat already does; pyproject.toml cannot express -c itself.)
# Each line is here because a different version broke a real run:
#   torch 2.8.0+cu128 : the LOCAL version suffix is deliberate. whisperx 3.8.6
#                       requires torch~=2.8.0 and torchvision 0.23.0 requires
#                       torch==2.8.0, so the resolver otherwise satisfies them
#                       with the plain PyPI `2.8.0+cpu` wheel -- silently
#                       dropping CUDA. `+cu128` is the Blackwell/RTX-50xx build
#                       and cannot be satisfied by the CPU wheel. A torch
#                       2.9+ build (e.g. 2.11.0+cu128) is UNSATISFIABLE with
#                       whisperx/torchvision here, so this pin refuses rather
#                       than swapping.
#   numpy 2.x         : whisperx/pyannote require >=2.1, while madmom needs
#                       the removed np.int / ragged-asarray behaviour -- both
#                       are reconciled at runtime by boo_lab._natten_compat.
#   NATTEN 0.21.x     : allin1 calls the pre-0.17 API; _natten_compat restores it.
#   allin1 1.1.0 / madmom 0.16.1 : the structure backend.
torch==2.8.0+cu128
torchaudio==2.8.0+cu128
torchvision==0.23.0+cu128
numpy>=2.1,<3
allin1==1.1.0
NATTEN>=0.21,<0.22
madmom==0.16.1
beat-this==1.1.0
whisperx==3.8.6

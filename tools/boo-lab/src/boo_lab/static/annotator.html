How to mark a song

Boxes are wavesurfer regions. Drag the body, drag an edge, click empty wave to seek. Overlaps are allowed when the roles differ. Each row also carries a figure id, a source, and an heard checkbox.

Heard — a box is only saved when you tick heard (you actually listened to it). Unheard boxes and raw drafts are dropped on Save. A heard draft becomes guess-accepted; a heard human box stays human.

Same-role overlap — two boxes of the same role overlapping by more than 50 ms is rejected with the pair shown. Different roles (a figure over a function) may overlap freely.

Identity — each box carries form (large letter, default A) + figure id (small, e.g. riff-A) + role, plus unique (single-use / through-composed figure), instrument (when two guitars differ), and start/end bars (1-based GP measures; filled on Save only when the tab matches).

Buttons

  • Intro — pads, swell, count-in
  • Build — rising into a drop
  • Riff — the repeating guitar idea
  • Hook — the bit you hum
  • Breakdown — half-time slam. Layer on a Riff if the guitar does not change
  • Solo / Chill / Pulse / Outro

Keys

  • Space — play / pause
  • 1 riff · 2 hook · 3 breakdown · 4 solo
  • I intro · B build · C chill · P pulse
  • S save · N next with tab · J / K next / previous song
  • Delete — remove selected box · Ctrl+Z undo · ? this panel

Guess / Lyrics / Pack

Guess — GP markers + Demucs drums + librosa half-time. Adds source=guess draft boxes (unheard). The status line also reports how much of the track Guess actually reached.

Load drafts — pull MSA source=msa-draft boxes from data/drafts.jsonl for this song, appended into the table as unheard. Tick heard to accept one as guess-accepted. Drafts are never auto-saved and Save never rewrites drafts.jsonl.

Stem picker — under the drums lane, switch between any cached demucs stem: drums / bass / guitar / piano / other / vocals (6-stem). Playhead stays linked to the mix.

Drum confidence — if the per-section classifier flags snare-undercount on a dense mix, the lane says so; hover for the reason. Treat those boxes as “verify by ear”, not ground truth.

VAL badge — songs reserved for the whole-song validation split are tagged VAL in the header; everything else is training.

Lyrics — fetch timed lines. Click a line to seek. − / + moves that line 0.2s. all −/+ shifts the whole song. Save lyrics writes work/lyrics.

Push git — commits src + data + lyrics in the god-tier-metal repo and pushes. Needs git remotes already set on your machine.

Pack — after Save, cut mix/drums/bass/other/guitar/piano/vocals/no-vox for every box on this song into work/pack (plus a train/val tag).

Remove album — deletes the selected song's whole album (FLACs + GP) from the corpus, drops its labels and holdout rows, then rescans. Only touches files under the configured FLAC/GP roots, and asks for confirmation.

Drop (sidebar) — type band name, drop zip/FLAC/GP. Copies into the corpus. Does not rename your rips.

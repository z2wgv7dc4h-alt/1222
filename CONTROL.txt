==================================================
COMMANDS
==================================================
/next     Do the next TASKS checkbox. Use this every time.
/scope    Open the right scope headings only. Use if /next skipped them.
/port     Port one symbol from reference\ using PORTS.md. Use when
          the task says "Port VoiceLeader" etc.
/close    Force doc+git bookkeeping if Stop did not.
/clear    New empty chat. You must type this. Hooks cannot.
/plan     Plan mode (or Shift+Tab). Use if it starts coding blind.
/compact  Only if the window is huge AND you are mid-box.
          Prefer /clear after a finished box.

Shift+Tab  Cycle permission mode.
           Leave Auto OFF when you walk away.
           Plan = look, don't edit.

How to mark a song

Boxes are wavesurfer regions. Drag the body, drag an edge, click empty wave to seek. Overlaps are allowed when the roles differ.

Buttons

  • Intro — pads, swell, count-in
  • Build — rising into a drop
  • Riff — the repeating guitar idea
  • Hook — the bit you hum
  • Breakdown — half-time slam. Layer on a Riff if the guitar does not change
  • Solo / Chill / Pulse / Outro

Keys

  • Space — play / pause
  • 1 riff · 2 hook · 3 breakdown · 4 solo
  • I intro · B build · C chill · P pulse
  • S save · N next with tab · J / K next / previous song
  • Delete — remove selected box · Ctrl+Z undo · ? this panel

Guess / Lyrics / Pack

Guess — GP markers + Demucs drums + librosa half-time. Optional draft boxes.

Lyrics — fetch timed lines. Click a line to seek. − / + moves that line 0.2s. all −/+ shifts the whole song. Save lyrics writes work/lyrics.

Push git — commits src + data + lyrics in the god-tier-metal repo and pushes. Needs git remotes already set on your machine.

Pack — after Save, cut mix/drums/bass/other/vocals/no-vox for every box on this song into work/pack.

Drop (sidebar) — type band name, drop zip/FLAC/GP. Copies into the corpus. Does not rename your rips.

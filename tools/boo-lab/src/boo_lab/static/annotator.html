How to mark a song

Quick start: (1) pick a song on the left and wait until the clock shows its full length. (2) Press a role pin (or 1 for Riff). Then drag the box to fit. (3) Tick heard on every box you actually listened to. (4) Press Save.

Guess and Load drafts are suggestions. They are not saved until heard and Save. Do not Guess a finished song. Do not pin VAL.

Figure is the riff's name. Same idea later = same figure (riff-A).

Drag a box to move it, drag its edge to resize, click empty sound to jump there. Boxes may overlap only when their roles differ (e.g. a Breakdown sitting on a Riff).

Lanes and right-click

  • One lane per role, top to bottom Intro → Outro. A box sits only in its role's lane, so a Riff + Breakdown + Outro stack shows as three bars at once.
  • Click a bar to select its table row (or click a row to light its bar). Right-click a bar to edit role / figure / heard / unique / inst, Play box, Split at playhead, or Delete. Double-click a bar toggles heard.
  • synth is an instrument (inst), not a role. All / Figures / Functions filters only hide bars and rows — Guess still drafts only, never a keeper.

What each table column means

  • role — what the section is (pick from the list below). The only required label.
  • figure — a name for the musical idea, e.g. riff-A. Same idea coming back? Keep the same name. New idea? New letter.
  • form — big-picture letter for the song part (A, B, C…). Usually leave it A.
  • uniq — tick if this idea happens only once (nothing repeats it).
  • inst — which instrument leads here (rhythm / lead / bass / synth…). Blank is fine.
  • bar0 / bar1 — the tab's measure numbers; filled in automatically on Save when a Guitar Pro tab matches, otherwise blank.
  • start / end — seconds in the audio; set by the box you drew.
  • source — where the row came from (human, or a draft like Guess / msa-draft). Leave it — Save handles it.
  • heard — tick once you've truly listened. Unticked boxes are thrown away on Save.

heard is the gate. Only ticked boxes are saved (as human, or guess-accepted if the row started as a draft). Nothing unticked survives. Undo (button or Ctrl+Z) steps back through this session's edits; each Save also keeps the previous file as data/sections.jsonl.bak.

Same-role overlap — two boxes of the same role overlapping by more than 50 ms refuses the whole Save and names the pair. Different roles may overlap freely.

Roles (pick the plainest one)

  • Intro — the opening (pads, swell, count-in).
  • Riff — the repeating guitar idea.
  • Hook — the bit you hum / the chorus.
  • Breakdown — the half-time slam. Can sit on top of a Riff if the guitar doesn't change.
  • Build — a rise that isn't the hook itself.
  • Solo — a lead / melodic excursion.
  • Chill — the energy sits down (a real breather, not just a quiet intro).
  • Pulse — a named synth / keyboard loop you can hum.
  • Outro — the ending.

Rule of thumb: Riff/Hook/Solo/Pulse describe a figure; Intro/Build/Breakdown/Chill/Outro describe a function. Figure and function boxes can overlap.

Keys

  • Space — play / pause
  • 1 riff · 2 hook · 3 breakdown · 4 solo
  • I intro · B build · C chill · P pulse
  • S save · N next with tab · J / K next / previous song
  • Delete — remove selected box · Ctrl+Z undo · ? this panel

Guess, drafts and the rest

Guess — proposes boxes from the Guitar Pro tab's markers plus simple audio cues (half-time / kick) on the isolated drums. They arrive as unheard source=guess rows. It labels only what it can justify; the status line tells you how far it got — paint the rest by hand.

Load drafts — pulls machine drafts (allin1 msa-draft, etc.) for this song and appends them unheard. Tick heard to keep one. Drafts are never saved by themselves, and Save never rewrites them.

Stem picker — listen to any cached demucs stem (drums / bass / guitar / piano / other / vocals); the playhead stays linked to the mix.

Drum confidence — if the classifier suspects it undercounted snares on a dense mix, it says so; treat those as "verify by ear".

VAL badge — this song is held out for validation; leave it unpinned.

Lyrics — fetch timed lines; click a line to seek; ± moves it 0.2 s; Save writes under work/lyrics.

Pack — after Save, cut per-box audio clips (mix + stems) into work/pack, tagged train/val.

Push git / Remove album / Drop — commit and push the repo; delete a whole album from the corpus (asks first, only touches files under the configured roots); or add a band by dropping a zip/FLAC/GP.
